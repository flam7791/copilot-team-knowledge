# Example knowledge base

`harbour-data-team` is a **fictional** analytics team. Its cards show every type and every
status, and three deliberate edge cases:

| Card | Why it is there |
|---|---|
| DEC-0001 | Superseded by DEC-0003: kept for the record, never published |
| DEC-0004 | A draft proposal: never published, and the agent must not present it as a decision |
| FCT-0003 | Classified restricted, above the publish ceiling: never published |

`_published/` holds the output of `teamkb bundle`, committed so you can see exactly what Copilot
would read. Names, sites and links (`contoso.sharepoint.com`) are placeholders.
